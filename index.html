Backpropagation

Backpropagation is a machine learning technique essential to the optimization of artificial neural networks.

It facilitates the use of gradient descent algorithms to update network weights which is how

the deep learning models driving modern artificial intelligence (AI) “learn”.

Activation Function

Each neuron first calculates a weighted sum of its inputs and adds a bias.

An activation function is then applied to introduce non-linearity into the network.

𝑓(𝑥) has to be a non-linear function, otherwise the neural network will only be able to learn linear models.

example : Sigmoid Function

Loss Function

After forward propagation, the network produces a prediction.

We compare this prediction with the actual target to measure how wrong the network is.

This difference is measured using a loss function.

example : L = (y - ŷ)². [MSE]

A smaller loss means the prediction is closer to the actual value.
